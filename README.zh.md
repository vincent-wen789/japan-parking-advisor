# Japan Parking Advisor（日本停车助手）

**在日本停车有三个 Google Maps 从不提的坑：限高栏杆你的车过不去、停错地方价格翻三倍、"满了"的牌子你开到了才看见。**

NAVITIME、タイムズ 这些 app 会帮你——前提是你付它们高级版的钱，而且愿意对着一张表自己筛。这个工具直接给你**结论**：停哪、按**你的车**筛、按**你这趟**比花费，连"到底进不进得去"都先帮你拦下来——跑在你本来就在用的 ChatGPT / Claude / Gemini 里。

> 🌏 **English →** [README.md](README.md) ・ **日本語はこちら →** [README.ja.md](README.ja.md)

## 从这里开始（60 秒，什么都不用装）

1. **点这个链接打开 prompt（prompt＝发给 AI 的那段指令文）：[`prompt/PROMPT.zh.md`](prompt/PROMPT.zh.md)**（也有 [English](prompt/PROMPT.md) / [日本語](prompt/PROMPT.ja.md) 版）。
2. 复制 **`---` 分割线以下的全部内容**——从"你是一个**日本**停车决策助手"开始，一直到最后。
3. 粘进任何**能联网搜索**的 AI 聊天——多数免费版现在都带联网搜索。如果你那个搜不了网，prompt 会自己说明并停下，不会瞎编。
4. 告诉它你去哪、开什么车：*"明天去川越老街，停 3 小时左右——本田 Freed。"* 租车还不知道具体车型？说车级就行——*"租的紧凑 SUV，车型未定"*——它会按保守值算（機械式塔库在真实车高确认前直接排除），并告诉你提车时要核对什么。

**贴一次，整趟旅行反复用**：干脆留着那个对话，之后直接发新目的地进去（任何档位都行）；套餐支持的话，也可以存成自定义 GPT / Project / Gem。

**费用：这个 prompt 免费。** 不用注册、不用 API key、不用安装——搜索是你手上那个 AI 聊天自己做的。一次回答大约要**一两分钟的联网搜索**（付费版一般搜得更深）；它在查真实页面，不是背一个过期数据库。

（还有一个给"跑 AI agent 的人"用的完整 skill——同一套引擎，只是在此之上多了已核验的车库名片链接。就是 `skill/` 目录，见下面"两个层级"。如果你不知道"AI agent"是什么，上面的复制粘贴版就是完整产品。）

## 为什么有这个工具

你在一个陌生的日本城市。Google Maps 说你到了——可到底停哪？看着便宜的コインパーキング，开近一看是限高 1.55m 的機械式塔库，你的车进不去。随便挑一个，没有最大料金，停 3 小时被收 ¥4,000。而那个又近又划算的——你开过去才发现满了。

Google Maps 能告诉你哪里有停车场，但它不会告诉你：
- **我的车开得进去吗？** 限高、機械式车库的陷阱（限高 1.55m 的立体塔库会把大多数 SUV 挡在外面；有些库只有自走层能停）。
- **对我这趟哪个更划算？** 它把成本要素摊给你比——时间料金 vs 最大料金 vs 提携割引；但它**不**替你精算到日元的"净最便宜"（割引随小票/店铺/当日变，算错比不算更糟）。
- **开过去发现满了怎么办？**——最高频的真实失败。所以这个工具永远给**并列备选**，而不是只给一个答案。（它不查实时空位——备选是路线选项，不是有位保证。）

范围：**专门针对日本**（数据源、搜索词、车库类型如 自走式/機械式、割引规则都是日本的）。停车是地域性极强的问题——这不是一个放之四海皆准的工具。底层机制理论上可改指向别国，但现状假设的就是日本，日本以外不支持。

## 不是又一个停车 app

| | NAVITIME / タイムズ 这类 app | 日本停车助手 |
|---|---|---|
| 你拿到的 | 能搜的数据库——自己筛 | 拍好的结论——按你的车、按你这趟 |
| 你的车进不进得去 | 自己一个个核限高 | 先帮你筛掉进不去的；查不到的限高当场标出来，不瞎猜 |
| 花你多少钱 | 订阅 / 付费高级版 | 免费——一段跑在你现有 AI 聊天里的 prompt；不用再多付一份订阅 |
| "满了"怎么办 | —— | 并列备选，不用绕着街区打转 |

而且它**不知道就说不知道**——限高没查到会标出来、绝不瞎猜——跟那种自信地答错的 AI 正相反。

**"我直接裸问 ChatGPT 不行吗？"** 行——但它不会主动查限高（除非你想起来问）、只给一个答案没有备选、还会顺手编一个点开是错车库的链接。这个 prompt 存在的意义就是把裸问会跳过的检查全部强制执行：先问车、限高不明必须标、并列备选、链接不许编。

## 一次回答长什么样

用仓库自带的已核验示范数据（横滨，2026-05 确认）拼出来的样例——两种层级、任何语言，形状都是这样：

> **你：** 明天开车去そごう横浜店，购物 3 小时左右。车是本田 Freed。
>
> **AI：** 横滨站东口一带，停约 3 小时。你的 Freed（约 1.71m 高——如遇临界车库，建议对一眼车检证）：下面两个都进得去，但注意そごう的塔库区。
>
> **横浜ベイクォーター駐車場**（首选）——自走式，730 台，¥340/30分；店内消费满 ¥3,000 免 1 小时。限高 2.20m，余量充足。
> https://maps.google.com/?cid=13690509701379998062
>
> **そごうパーキング館**（就在商场）——¥340/30分，そごう小票满 ¥3,000 免 1.5 小时。**条件可入：平面区（2.10m）能进；塔库区限高 1.50m 进不去——入口处务必要平面区（开口/出示这句就行：「平面でお願いします」）。**
> https://maps.google.com/?cid=7086177179481059382
>
> *（……真实回答里还会再给 1–2 个并列备选——首选满了就直接去下一个，这是设计好的正常路径，不算失败。）*
>
> 两个都是自走式；料金来自官方页面——以现场看板为准。

そごう那一条就是这个工具的全部意义：Google Maps 能显示这两个车库，但不会告诉你其中一个只有某些楼层你的车能进。

## 两个层级 —— 该用哪个

**一句话选：不懂技术 / 只想要答案 → L2（就是上面"从这里开始"那四步）。你在跑 AI agent（Claude Code 等）、想要点进去就是那个车库的已核验链接 → L1。**

| 层级 | 是什么 | 链接质量 | 需要 | 什么时候用 |
|---|---|---|---|---|
| **L1 — skill**（`skill/`） | 完整的 agent skill | **已核验的直达车库链接**（点进去就是那个车库名片）——*仅在有 headless 浏览器栈时*；否则降级成普通链接并说明 | 联网搜索 API + headless 浏览器 + 网页抓取器（见 `skill/SETUP.md`）；为 Claude Code 这类 agent 设计 | 你跑 agent、想要最好的已核验链接 |
| **L2 — prompt**（`prompt/`） | 一段复制粘贴的 prompt | 普通 Maps 链接——**无法核实链接指向的就是那个对的车库**（防同名连锁 / 租车店的消歧只有 L1 有，所以开车前要自己点开确认） | 任何带联网搜索的 LLM | 你只想要个快答案、零配置 |

**没在跑 agent 的人，大多数该用 L2。** 它做同样的搜索 + 车筛 + 诚实推理——代价是每个链接你得自己点开确认（看 pin 是不是钉在你目的地旁边），再开车。

### 设计（一套引擎，两层壳）
L1 和 L2 共用一套引擎——同样的数据/过滤/呈现模型、同样的诚实规则、同样的排序。只有运行环境不同（带浏览器的 agent → 满血；聊天 LLM → 降级）。两层都必须满足的共同规则写在 [`skill/ENGINE-INVARIANTS.md`](skill/ENGINE-INVARIANTS.md)。

## 安装

**L1（skill）**：把 `skill/` 目录拷进你 agent 的 skills 文件夹（Claude Code 是 `~/.claude/skills/japan-parking-advisor/`），然后按 [`skill/SETUP.md`](skill/SETUP.md) 配三个依赖（搜索 API / headless 浏览器 / 抓取器）。没有 headless 浏览器它也能跑——链接降级成普通 Maps + 一句提示。

**L2（prompt）**：就是页首"从这里开始"那四步——打开 [`prompt/PROMPT.zh.md`](prompt/PROMPT.zh.md)，复制分割线以下全部，粘进任何带联网搜索的 LLM，告诉它你去哪、开什么车。

## 数据诚实怎么处理

异常触发：它**不会**逐条报来源/日期/可信度（那是噪音）。只在某条**真有问题**时才出声。**唯一的硬规则**：限高/限幅未确认必须**当场说**——"我的车能不能进"是安全问题不是噪音——而且这种车库绝不当首选。

## 关于速度（冷启动）

这个开源版是**联网搜索优先**——它带一个小的示范数据集，**不是**预建的区域缓存。所以第一次查一个新地方会慢一些（预期一两分钟的搜索）、确定性低一些。你可以随时间自己攒本地缓存（示范数据集的格式见 `skill/references/parking-data.md`）。

## 御三家 LLM 的已知差异

三家大 LLM 在 L2 prompt 上行为不同（联网搜索默认值、链接格式）。不承诺等价——真实粘贴实测记录见 [`KNOWN-DIFFERENCES.md`](KNOWN-DIFFERENCES.md)。三家都通过了实测；有一个值得提前知道的怪癖：**Gemini 打不开 Google Maps 短链接**——它会改问你店名+地址。
