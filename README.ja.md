# Japan Parking Advisor（日本の駐車場アドバイザー）

日本で車を運転する人のための駐車場意思決定アシスタント——地域性が非常に強く、日本に特化した設計で、世界共通の解ではありません。目的地を伝えると、ライブWeb検索し、**あなたの車**で絞り込み、第一候補と2〜3個の並列の近隣代替案を返します——それぞれにGoogleマップ・リンク付き。

> 🌏 English: [README.md](README.md) ・ 中文: [README.zh.md](README.zh.md)

## なぜ必要か

Googleマップは駐車場の場所は教えてくれますが、次のことは教えてくれません：
- **自分の車は物理的に入れるのか？** 高さ制限と機械式駐車場の罠（高さ1.5mのタワー式は大半のSUVを弾く；自走階にしか停められない駐車場もある）。
- **今回の滞在で実際にどこが一番安いのか？** 時間料金 vs 最大料金 vs 提携割引。
- **着いたら満車だったらどうする？**——最も頻発する実際の失敗。だからこのツールは1つの答えではなく、常に**並列の代替案**を出します。

対象範囲：**日本専用**（情報源・検索クエリ・駐車場の種別（自走式/機械式）・割引慣行はすべて日本向け）。駐車場選びは地域性が非常に強い問題であり、これは世界共通のツールではありません。基盤となる仕組みは他国向けに作り直すことは可能ですが、現状のままでは日本を前提としており、国外は非対応です。

## 2つの層 —— どちらを使うか

| 層 | 内容 | リンク品質 | 必要なもの | こんな時に |
|---|---|---|---|---|
| **L1 — スキル**（`skill/`） | フルのエージェント・スキル | **WYSIWYGプレイスカード・リンク**（*headlessブラウザ環境がある場合のみ*）；無い場合は丁寧にダウングレード + その旨を明示 | Web検索API + headlessブラウザ（`skill/SETUP.md` 参照）；Claude Code系エージェント向け | エージェントを動かしていて、検証済みの最良リンクが欲しい時 |
| **L2 — プロンプト**（`prompt/`） | コピペ用プロンプト | 通常のMapsリンク——**リンクが正しい駐車場を指しているか検証できない**（同名チェーン / レンタカー店の判別はL1のみ） | ライブWeb検索ができるLLMなら何でも | とにかく手早く答えが欲しい、設定ゼロで使いたい時 |

**エージェントを動かしていない人の多くはL2が向いています。** 同じ検索 + 車での絞り込み + 誠実な推論を行います；出発前に各リンクを開いて目的の駐車場か確認するだけです。

### 設計（1つのエンジン、2つの外殻）
L1とL2は1つのエンジンを共有します——同じデータ/フィルタ/提示モデル、同じ誠実ルール、同じ並べ替え。違うのは実行環境だけ（ブラウザ付きエージェント → フル；チャットLLM → ダウングレード）。両層が満たすべき共通ルールは [`skill/ENGINE-INVARIANTS.md`](skill/ENGINE-INVARIANTS.md) に記載。

## インストール

**L1（スキル）**：`skill/` ディレクトリをエージェントのスキルフォルダにコピーし、[`skill/SETUP.md`](skill/SETUP.md) に従って3つの依存（検索API / headlessブラウザ / フェッチャー）を設定。headlessブラウザが無くても動きます——リンクが通常のMaps + 注記にダウングレードされるだけです。

**L2（プロンプト）**：[`prompt/PROMPT.ja.md`](prompt/PROMPT.ja.md)（または [`.md` 英語](prompt/PROMPT.md) / [`.zh` 中国語](prompt/PROMPT.zh.md)）を開き、区切り線より下をすべてコピーして、ライブWeb検索ができるLLMに貼り付け、行き先と車種を伝えてください。

## データの誠実さの扱い

例外トリガー型：毎行に出典/日付/信頼度を並べません（ノイズになる）。本当に何かおかしい時だけ声を上げます。**唯一のハードルール**：高さ・幅制限が不明な場合は必ず**その場で述べる**——「自分の車が入れるか」は安全であってノイズではない——そしてそのような駐車場は決して第一候補にしません。

## 速度について（コールドスタート）

このOSS版は**ライブ検索優先**です——小さなデモ用データセットは同梱しますが、構築済みの地域キャッシュは**ありません**。そのため、新しいエリアの初回クエリは、プライベートにキャッシュした環境より遅く、やや不確実です。時間をかけて自分のローカルキャッシュを育てられます（デモ用データセットの形式は `skill/references/parking-data.md` を参照）。

## LLMごとの既知の差異

3大LLMはL2プロンプトで挙動が異なります（Web検索のデフォルト、リンク書式）。等価性は保証しません——[`KNOWN-DIFFERENCES.md`](KNOWN-DIFFERENCES.md) を参照。
