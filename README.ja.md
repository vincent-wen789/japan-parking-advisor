# Japan Parking Advisor（日本の駐車場アドバイザー）

**日本の駐車場には、Googleマップが決して教えてくれない3つの罠があります：あなたの車が通れない高さ制限、選び間違えると3倍になる料金、そして着いてから初めて見る「満車」の表示。**

NAVITIME や タイムズ のアプリは助けてくれます——有料プランの料金を払い、リストを自分で読んで自分で絞り込むなら。このツールは代わりに**結論**を渡します：どこに停めるか、**あなたの車**で絞り込み、**今回の滞在**で費用を比較し、「そもそも入れるのか」のチェックを先に済ませて——あなたが既に使っている ChatGPT / Claude / Gemini の中で動きます。

> 🌏 **English →** [README.md](README.md) ・ **中文版 →** [README.zh.md](README.zh.md)

## まずはここから（60秒・インストール不要）

1. **このリンクをタップ/クリックしてプロンプトを開く（プロンプト＝AIに渡す指示文のこと）：[`prompt/PROMPT.ja.md`](prompt/PROMPT.ja.md)**（[English](prompt/PROMPT.md) / [中文](prompt/PROMPT.zh.md) 版もあります）。
2. **`---` の区切り線より下をすべて**コピーする——「あなたは**日本**の駐車場意思決定アシスタントです」から最後まで。
3. **Web検索ができる** AIチャットに貼り付ける——多くの無料プランでもWeb検索が使えます。検索できないAIの場合、プロンプト自身が「できない」と述べて止まります（当てずっぽうは返しません）。
4. 行き先と車種を伝える：*「明日、川越の蔵造りの町並みへ。3時間くらい——ホンダ・フリード」*。レンタカーで車種がまだ分からない？クラスだけでOK——*「レンタカーのコンパクトSUV、車種未定」*——安全側で計算し（実車高が確認できるまで機械式・タワー式は除外）、受け取り時に何を確認すべきか教えてくれます。

**1回貼れば、旅行中ずっと使えます**：そのチャットを残して次の行き先を送るだけでOK（どのプランでも可）；プランが対応していれば カスタムGPT / Project / Gem として保存もできます。

**費用：このプロンプトは無料です。** 登録も API キーもインストールも不要——検索するのはあなたが今使っているAIチャットです。回答には**1〜2分ほどのWeb検索**がかかります（有料プランの方が深く検索する傾向）；古いデータベースの暗唱ではなく、実際のページを確認しているためです。

（AIエージェントを動かしている人向けに、同じエンジンに検証済みのプレイスカード・リンクを追加するフル版スキルもあります——それが `skill/` ディレクトリで、下の「2つの層」で説明します。「AIエージェント」にピンと来なければ、上のコピペ版がこの製品のすべてです。）

## 回答のイメージ

リポジトリ同梱の検証済みデモデータ（横浜・2026-05確認）で組んだサンプルです——どちらの層でも、どの言語でも、この形になります：

> **あなた：** 明日そごう横浜店へ車で行きます。買い物3時間くらい。車はホンダ・フリード。
>
> **AI：** 横浜駅東口エリア、約3時間の駐車ですね。フリード（全高約1.71m——際どい駐車場では車検証の確認をおすすめ）：下の2つはどちらも入れますが、そごうのタワー式ゾーンに注意。
>
> **横浜ベイクォーター駐車場**（第一候補）——自走式・730台・¥340/30分；店内¥3,000以上の利用で1時間無料。制限高2.20mで余裕あり。
> https://maps.google.com/?cid=13690509701379998062
>
> **そごうパーキング館**（お店の真上）——¥340/30分、そごうで¥3,000以上の購入で1.5時間無料。**条件付き：平面ゾーン（2.10m）は入れますが、タワー式ゾーンは制限高1.50mで入れません——入口で必ず平面ゾーンを指定してください。**
> https://maps.google.com/?cid=7086177179481059382
>
> *（…実際の回答ではさらに1〜2件の並列代替案が付きます——第一候補が満車でも次へ行くだけ。それが設計上の正常ルートで、失敗ではありません。）*
>
> どちらも自走式；料金は公式ページ由来——現地の看板が正です。

そごうの行こそがこのツールの核心です：Googleマップは両方の駐車場を表示しますが、「片方はあなたの車が特定の階にしか入れない」ことまでは教えてくれません。

## なぜ必要か

見知らぬ日本の街にいます。Googleマップは「到着しました」と言う——でも実際どこに停める？安そうなコインパーキングは、近づくと高さ1.55mの機械式タワーで、あなたの車は入れません。適当に選んだ所は最大料金がなく、3時間で¥4,000。そして良さげな駐車場は——着いてから満車だと気づきます。

Googleマップは駐車場の場所は教えてくれますが、次のことは教えてくれません：
- **自分の車は物理的に入れるのか？** 高さ制限と機械式駐車場の罠（高さ1.55mのタワー式は大半のSUVを弾く；自走階にしか停められない駐車場もある）。
- **今回の滞在でどこがより安いか？** コスト要因（時間料金 vs 最大料金 vs 提携割引）を比較できる形で提示します；ただし円単位の「実質最安」までは計算しません（割引はレシート/店舗/曜日で変わり、誤った計算はしないより悪いため）。
- **着いたら満車だったらどうする？**——最も頻発する実際の失敗。だからこのツールは1つの答えではなく、常に**並列の代替案**を出します。（リアルタイムの空き状況は確認しません——代替案はルートの選択肢で、空車保証ではありません。）

対象範囲：**日本専用**（情報源・検索クエリ・駐車場の種別（自走式/機械式）・割引慣行はすべて日本向け）。駐車場選びは地域性が非常に強い問題であり、これは世界共通のツールではありません。基盤となる仕組みは他国向けに作り直すことは可能ですが、現状のままでは日本を前提としており、国外は非対応です。

## ただの駐車場アプリではありません

| | NAVITIME / タイムズ系アプリ | 日本の駐車場アドバイザー |
|---|---|---|
| 得られるもの | 検索できるデータベース——自分で絞り込む | 結論——あなたの車で絞り込み、今回の滞在で費用比較済み |
| 車が入れるか | 各駐車場の高さを自分で確認 | 先に除外；高さが未公表なら推測せず明示 |
| かかる費用 | サブスク / 有料プラン | 無料——今使っているAIチャットの中で動くプロンプト；追加のサブスク不要 |
| 満車のとき | —— | 並列の代替案で、街をぐるぐる回らずに済む |

そして**分からない時は分からないと言います**——未確認の高さ制限は推測せず明示する——自信満々に間違える AI の正反対です。

**「普通にChatGPTに聞けばいいのでは？」** 聞けます——ただし、こちらから頼まない限り高さのチェックは飛ばされ、代替案なしの答えが1つ返り、同名の別駐車場が開くリンクを平気で作られます。このプロンプトの存在意義は、素のAIが飛ばすチェックを強制することです：まず車を聞く・高さ不明は必ず明示・並列の代替案・リンクの捏造禁止。

## 2つの層 —— どちらを使うか

**ひとことで選ぶ：技術に詳しくない / とにかく答えが欲しい → L2（上の「まずはここから」の4ステップ）。AIエージェント（Claude Code 等）を動かしていて、クリックでその駐車場に直行する検証済みリンクが欲しい → L1。**

| 層 | 内容 | リンク品質 | 必要なもの | こんな時に |
|---|---|---|---|---|
| **L1 — スキル**（`skill/`） | フルのエージェント・スキル | **検証済みの直行リンク**（クリック→その駐車場のプレイスカード）——*headlessブラウザ環境がある場合のみ*；無ければ通常リンクにダウングレードしその旨を明示 | Web検索API + headlessブラウザ + ページ取得ツール（`skill/SETUP.md` 参照）；Claude Code系エージェント向け | エージェントを動かしていて、検証済みの最良リンクが欲しい時 |
| **L2 — プロンプト**（`prompt/`） | コピペ用プロンプト | 通常のMapsリンク——**リンクが正しい駐車場を指しているか検証できない**（同名チェーン / レンタカー店の判別はL1のみ、だから運転前に各自で開いて確認） | ライブWeb検索ができるLLMなら何でも | とにかく手早く答えが欲しい、設定ゼロで使いたい時 |

**エージェントを動かしていない人の多くはL2が向いています。** 同じ検索 + 車での絞り込み + 誠実な推論を行います；出発前に各リンクを開いて（ピンが目的地のそばに立っているか）確認するだけです。

### 設計（1つのエンジン、2つの外殻）
L1とL2は1つのエンジンを共有します——同じデータ/フィルタ/提示モデル、同じ誠実ルール、同じ並べ替え。違うのは実行環境だけ（ブラウザ付きエージェント → フル；チャットLLM → ダウングレード）。両層が満たすべき共通ルールは [`skill/ENGINE-INVARIANTS.md`](skill/ENGINE-INVARIANTS.md) に記載。

## インストール

**L1（スキル）**：`skill/` ディレクトリをエージェントのスキルフォルダにコピーし（Claude Code なら `~/.claude/skills/japan-parking-advisor/`）、[`skill/SETUP.md`](skill/SETUP.md) に従って3つの依存（検索API / headlessブラウザ / フェッチャー）を設定。headlessブラウザが無くても動きます——リンクが通常のMaps + 注記にダウングレードされるだけです。

**L2（プロンプト）**：ページ上部「まずはここから」の4ステップの通り——[`prompt/PROMPT.ja.md`](prompt/PROMPT.ja.md) を開き、区切り線より下をすべてコピーして、Web検索ができるLLMに貼り、行き先と車種を伝えてください。

## データの誠実さの扱い

例外トリガー型：毎行に出典/日付/信頼度を並べません（ノイズになる）。本当に何かおかしい時だけ声を上げます。**唯一のハードルール**：高さ・幅制限が不明な場合は必ず**その場で述べる**——「自分の車が入れるか」は安全であってノイズではない——そしてそのような駐車場は決して第一候補にしません。

## 速度について（コールドスタート）

このOSS版は**ライブ検索優先**です——小さなデモ用データセットは同梱しますが、構築済みの地域キャッシュは**ありません**。そのため、新しいエリアの初回クエリは遅く（1〜2分の検索を見込んでください）、やや不確実です。時間をかけて自分のローカルキャッシュを育てられます（デモ用データセットの形式は `skill/references/parking-data.md` を参照）。

## LLMごとの既知の差異

3大LLMはL2プロンプトで挙動が異なります（Web検索のデフォルト、リンク書式）。等価性は保証しません——実際の貼り付けテストの記録は [`KNOWN-DIFFERENCES.md`](KNOWN-DIFFERENCES.md) を参照。3つとも合格していますが、先に知っておくべき癖が1つ：**GeminiはGoogleマップの短縮リンクを開けません**——代わりに店名+住所を聞いてきます。
